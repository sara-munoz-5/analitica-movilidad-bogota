# Análisis de Movilidad en Bogotá 2023

Proyecto académico de Analítica de Datos basado en la Encuesta de Movilidad de Bogotá 2023.

## Objetivo

Analizar los factores asociados con la elección entre transporte colectivo e individual motorizado, con el fin de identificar patrones útiles para el contexto comercial de DiDi.

## Contenido

- **Sección 1–4:** carga, integración, construcción del dataset y evaluación de calidad.
- **Sección 5:** limpieza, selección de características y preparación de transformaciones.
- **Sección 6:** análisis exploratorio, visualizaciones y contraste de hipótesis.
- **Sección 7:** modelado predictivo y evaluación (pendiente de integración).

## Ejecución

Consulta el [dashboard de Streamlit](dashboard_movilidad/README.md) para explorar la Entrega 3 y conocer las instrucciones de ejecución y despliegue.

1. Abrir `entrega_1.ipynb` en Google Colab.
2. Ejecutar las celdas en orden.
3. El notebook descarga automáticamente los datos oficiales necesarios.

## Fuente de datos

Encuesta de Movilidad de Bogotá 2023 — Secretaría Distrital de Movilidad y Observatorio de Movilidad de Bogotá.
